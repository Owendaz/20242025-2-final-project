迷宫生成与求解器 (Maze Generator and Solver)
1. 项目概述 (Project Overview)
本项目是一个基于 C++ 和 Qt 6 图形界面库开发的桌面应用程序，旨在实现《程序设计实践 II》课程任务书中要求的功能。程序能够动态生成多种类型的迷宫，并提供两种经典的寻路算法（DFS 和 BFS）来寻找路径。其最大的亮点是支持实时动画演示寻路过程，以及允许用户通过鼠标交互式地选择任意起点和终点。

2. 功能特性 (Features)
智能迷宫生成

稳定可靠: 采用迭代式深度优先搜索算法生成迷宫，从根本上解决了因递归过深导致的栈溢出问题，可稳定生成超大尺寸（如200x200）的迷宫。

多样化场景: 可一键生成三种不同特性的迷宫：

单路径迷宫：标准的“完美”迷宫，从起点到终点有且仅有一条通路。

多路径迷宫：在完美迷宫的基础上随机“破壁”，形成含有回路和多种解法的复杂迷宫。

无路径迷宫：在完美迷宫的基础上随机“建壁”，可能导致起点和终点之间不连通，用于测试算法的异常处理能力。

经典的寻路算法

深度优先搜索 (DFS): 快速找到迷宫中的任意一条有效路径。

广度优先搜索 (BFS): 保证找到起点和终点之间的最短路径。

现代化的交互体验

实时动画演示: 直观地展示DFS和BFS算法的完整探索过程。灰色代表已探索区域，橙色代表待探索的“前沿”区域，让算法逻辑一目了然。

任意点选: 用户可以通过鼠标左键点击选择起点，右键点击选择终点，程序会根据用户的选择进行寻路，极大地增强了交互性和自由度。

动态尺寸调整: 用户可以随时在界面上调整迷宫的宽度和高度，并立即生成新迷宫。

清晰的状态提示: 界面底部的状态栏会实时提供操作指引和结果反馈。

3. 技术栈 (Technology Stack)
核心语言: C++17

图形界面: Qt 6 Framework

构建系统: CMake

编译器: MinGW (或 MSVC)

4. 如何编译与运行 (Build and Run)
本项目使用 Qt Creator 作为推荐的开发环境。

环境配置:

安装 Qt (版本 >= 6.2)。

确保在安装 Qt 时，选择了与你的编译器匹配的组件（例如，MinGW 11.2.0 64-bit 或 MSVC 2019 64-bit）。

安装 CMake。

使用 Qt Creator 构建:

使用 Qt Creator 打开项目根目录下的 CMakeLists.txt 文件。

在首次打开时，Qt Creator 会提示你配置项目 (Configure Project)。选择一个你已安装的有效构建套件 (Kit)，例如 Desktop Qt 6.x.x MinGW 64-bit。

点击左下角的“电脑”图标，将构建模式切换为 Release。

点击菜单栏的“构建” -> “重新构建项目”。

点击绿色的“运行”按钮即可启动程序。

5. 如何使用 (How to Use)
调整尺寸 (可选): 在界面右上角输入期望的宽度和高度。

生成迷宫: 在“生成迷宫”区域，点击三个按钮中的任意一个来创建特定类型的迷宫。

开始寻路:

在“解决迷宫”区域，点击“动画演示 (DFS)”或“动画演示 (BFS)”按钮，程序将进入“点选模式”。

根据状态栏的提示，用鼠标左键在迷宫中点击任意位置作为起点。

再次根据状态栏的提示，用鼠标右键在迷宫中点击任意位置作为终点。

选择终点后，寻路动画将自动开始。

重新开始: 你可以随时生成新的迷宫，或者重新选择算法和起点/终点。

6. 关键算法解析 (Algorithm Explanation)
迷宫生成:
我们采用迭代实现的深度优先搜索（Recursive Backtracker算法的非递归版本）。使用一个std::stack来手动管理访问路径，代替函数调用栈。当探索到某点，随机选择一个未访问的邻居，打通墙壁并将其压入栈；若无路可走，则从栈中弹出节点进行回溯。这种方式避免了递归深度限制，可以安全地生成任意大的迷宫。

路径求解:

DFS: 使用std::stack作为前沿容器。其“后进先出”的特性使其会沿着一条路径不断深入，直到碰到死路才回溯。

BFS: 使用std::queue作为前沿容器。其“先进先出”的特性使其像水波纹一样，一层一层地向外探索，从而保证了第一次找到终点时，所经过的路径必然是最短的。
